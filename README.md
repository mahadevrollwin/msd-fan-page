# MSD Archive

Unofficial MS Dhoni fan page built with Next.js. Phase 2 is the complete frontend with temporary placeholder content. Sanity arrives in later phases.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env.local` when you need a public site URL for metadata and share links.
