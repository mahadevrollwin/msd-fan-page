# MSD Archive

Unofficial MS Dhoni fan page built with Next.js and Sanity CMS.

## Run locally

```bash
npm install
cp .env.example .env.local
```

Fill `.env.local` with the Sanity project ID and dataset, then:

```bash
npm run dev
```

- Site: [http://localhost:3000](http://localhost:3000)
- Studio: [http://localhost:3000/studio](http://localhost:3000/studio)
