# MSD Archive

Unofficial MS Dhoni fan page. Phase 1 is the Next.js shell: design system, header, footer, and responsive layout. Page sections and Sanity come in later phases.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env.local` when you need a public site URL for metadata. No API keys are required for this phase.
